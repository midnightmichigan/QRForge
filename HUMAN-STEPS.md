# Human steps — QRForge

**Status: nothing is published. The tool lives only in this workspace.**
Build cost: **$0**. No money has been spent.

## Try it right now (free)

1. Open `~/workspace/micro-software/qrforge/index.html` in any browser
   (double-click it — it works straight from `file://`, no server needed).
2. Make a code, download the SVG, and scan it with your phone camera.

## Optional: put it online (free)

If you want a public link, the cheapest honest path is free static hosting:

1. Create a free GitHub account (if you don't have one).
2. Create a public repository, upload the `qrforge` folder contents.
3. Enable **GitHub Pages** (Settings → Pages → Deploy from branch).
4. Your tool is live at `https://<you>.github.io/<repo>/` — free, no server to run.

Equivalents that also cost $0: Cloudflare Pages, Netlify Drop, Vercel static.

## What NOT to do

- **Do not buy a domain** for this unless you decide it yourself — it is not
  needed (GitHub Pages URLs work fine) and it costs money.
- **Do not pay for any "QR API", listing, or promotion service.** The tool is
  fully client-side; there is nothing to pay for.
- Any paid step at all is **your explicit decision**, unless it meets your own
  standing rule: ≤ ~$5 *and* it instantly unlocks an existing payout (immediate
  payback, not projected revenue). Nothing in this project qualifies.
